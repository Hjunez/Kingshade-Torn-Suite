READ THIS FIRST

Kingshade's Bootlegging Advisor helps manage all eight Bootlegging DVD genres.
It compares current stock with everything already copying or waiting in the queue,
then gives one clear recommendation:

COPY — manually copy the highlighted genre.
WAIT — the existing queue already covers the current shortage.
SELL — the projected stock is sufficiently balanced for a sale.

The script is read-only guidance. It does not click, copy, sell, spend nerve,
require an API key, contact an external service, or collect player identity.

IMPORTANT

1. Enable only one Bootlegging Advisor version.
2. Injection time must be START.
3. All game actions remain manual.
4. Do not spend nerve or sell only to create a test case.
5. Do not share API keys, login details, or private account information.
6. When reporting a problem, include the requested screenshot/video from that test step.
7. Use COPY SAFE DIAGNOSTIC only when numbers or recommendations appear wrong.
