# KS Knowledge Base

Purpose: give Codex a compact, searchable source map for recurring Kingshade development work without loading large references into every prompt.

## Read by task
- Algorithm design, correctness, complexity, recursion, DP, graphs, flows, NP-hardness: `algorithms-core.md`
- JavaScript/web/DOM basics: `javascript-web.md`
- Python basics: `python-basics.md`
- External reference registry and verification status: `sources.md`

## Retrieval rule
Read only the relevant note first. Consult original source material when a note is insufficient or when exact wording/proof/details matter.

## Source hierarchy
1. Current repository evidence and current task evidence.
2. Current official platform/API documentation for mutable behavior.
3. Original uploaded/reference material.
4. Curated notes in this directory.
5. Inference, which must be labeled as such.

The notes are navigation aids, not replacements for original sources.
